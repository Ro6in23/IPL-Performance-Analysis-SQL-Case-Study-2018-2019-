IPL Performance Analysis | SQL Case Study (2018–2019)
A data storytelling project that uses SQL (Google BigQuery) to analyze Indian Premier League player and team performance across two seasons. The goal was to surface actionable insights from raw match data — identifying dominant teams, aggressive batsmen, consistent performers, and clutch bowlers.
Key Questions Answered:

Which team scored the most runs in 2019?
Who was the most aggressive boundary hitter in 2018?
Which player performed consistently across both seasons?
Who were the most economical bowlers?
Which bowlers had match-defining 4-wicket hauls?

Skills Demonstrated: GROUP BY aggregation · Metric Engineering · INNER JOIN across seasons · Multi-criteria WHERE filtering · Exception reporting
Tools: Google BigQuery · SQL · HTML/CSS (portfolio deck)
